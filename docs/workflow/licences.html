ASign-up, trial and every launch

The first screen offers the plans; the account is a phone number and a password.

  U->>D: picks a plan, creates the account
name, business, phone, password
  D->>B: POST register {phone, password, device CD-XXXX-XXXX, offer}
  Note over B: trial of the plan picked, once per phone number
AND once per PC (an HMAC of both is kept)
  B-->>D: session token + signed licence (tier, PC, end date)
  Note over D: the local admin takes the BENS password,
opens straight away
  loop every launch
    D->>D: licence checked OFFLINE (Ed25519 signature, PC code, date)
    D->>B: check-in (background): licence, plan, Smart Scans
    B-->>D: up-to-date licence, or signed_out (account moved)
  end

BThe licence’s life

The licence is bound to the PC (its code CD-XXXX-XXXX from the machine id) and checked offline.

stateDiagram-v2
  [*] --> NoLicence
  NoLicence --> Trial: sign-up (plan picked)
  NoLicence --> Plan: key pasted (offline backup)
  Trial --> Plan: plan bought (check-in brings it)
  Trial --> ReadOnly: trial over
  Plan --> ReadOnly: end date passed
  ReadOnly --> Plan: plan bought
  Plan --> OtherPC: account signed in on another PC
  OtherPC --> NoLicence: next check-in signed_out
  • Read-only when the trial or plan ends: sign-in still works, only the consultation modules open (dashboard, sales, products, stock, third parties, history, zakat, settings); no creation, edit or export. Data is kept.
  • Forgotten password: the app shows a recovery code to send on WhatsApp; the dashboard gives a reset code (48 h) to type in the app.
  • Clock moved back: the licence is refused until the date is right again.
  • Backup restored from another PC: this PC keeps its own licence and BENS account.

AInscription, essai et chaque lancement

Le premier écran propose les formules ; le compte est un numéro de téléphone et un mot de passe.

  B-->>D: Basic, Advanced, Ultra avec prix, essai de 14 jours
  U->>D: choisit une formule, crée le compte
nom, commerce, téléphone, mot de passe
  D->>B: POST register {phone, password, device CD-XXXX-XXXX, offer}
  Note over B: essai de la formule choisie, une fois par numéro
ET une fois par poste (une empreinte HMAC des deux)
  B-->>D: jeton de session + licence signée (palier, poste, fin)
  Note over D: l'administrateur local prend le mot de passe BENS,
s'ouvre directement
  loop à chaque lancement
    D->>D: licence vérifiée HORS LIGNE (signature Ed25519, code du poste, date)
    D->>B: check-in (en arrière-plan) : licence, formule, Smart Scans
    B-->>D: licence à jour, ou signed_out (compte passé sur un autre poste)
  end

BLa vie de la licence

La licence est liée au poste (son code CD-XXXX-XXXX tiré de l'identifiant de la machine) et vérifiée hors ligne.

stateDiagram-v2
  [*] --> SansLicence
  SansLicence --> Essai: inscription (formule choisie)
  SansLicence --> Formule: clé collée (secours hors ligne)
  Essai --> Formule: formule achetée (arrive au check-in)
  Essai --> LectureSeule: essai terminé
  Formule --> LectureSeule: date de fin passée
  LectureSeule --> Formule: formule achetée
  Formule --> AutrePoste: compte connecté sur un autre poste
  AutrePoste --> SansLicence: check-in suivant signed_out
  • Lecture seule à la fin de l'essai ou de la formule : la connexion reste possible, seuls les modules de consultation s'ouvrent (tableau de bord, ventes, produits, stock, tiers, historique, zakat, paramètres) ; ni création, ni modification, ni export. Les données sont gardées.
  • Mot de passe oublié : l'application affiche un code de récupération à envoyer sur WhatsApp ; le tableau de bord donne un code de réinitialisation (48 h) à taper dans l'application.
  • Horloge reculée : la licence est refusée tant que la date n'est pas juste.
  • Sauvegarde d'un autre poste restaurée : ce poste garde sa licence et son compte BENS.
